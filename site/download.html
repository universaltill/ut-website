Android's installer will warn about "unknown sources" the first time — that's expected for an app outside the Play Store, not a sign anything is wrong. Tap through to allow it.

Windows installer, macOS app, Raspberry Pi/Linux .deb: the till opens in its own app window — no browser, no terminal. Windows: run the installer, then launch "Universal Till" from the Start menu/desktop shortcut. macOS: open the .dmg and drag Universal Till into Applications (first time, right-click → Open to clear the unsigned-app warning). Raspberry Pi/Debian/Ubuntu .deb: after sudo apt install ./unitill-pos_*.deb, "Universal Till" is in your applications menu. Portable .tar.gz/.zip archives: double-click unitill-desktop (or unitill-desktop.exe on Windows) for the same app-window experience; run-unitill.command/.sh/.bat is the alternative that opens your default browser instead. Dedicated Raspberry Pi till (no desktop needed): after installing the .deb, run sudo /opt/unitill/bin/unitill-kiosk-setup and reboot — the Pi boots straight into the till, fullscreen, no desktop at all.
