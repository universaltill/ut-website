Eine Kasse reicht, bis sie nicht mehr reicht: eine Schlange zur Mittagszeit, eine
zweite Theke, eine Terrasse, ein Tablet für die Küche. Mit Universal Till fügen
Sie demselben Geschäft weitere Kassen hinzu – ohne Netzwerktechniker und ohne
Cloud-Konto. Eine Kasse ist die **Hauptkasse**; die anderen **treten ihr bei**
und teilen Sortiment, Preise, Einstellungen und Bestand automatisch, über das
eigene Netzwerk Ihres Geschäfts.

## Eine neue Kasse in einer Minute koppeln

1. Gehen Sie an der Hauptkasse zu Einstellungen → Kassen und tippen Sie auf
   **Kopplungscode anzeigen**. Sie sehen einen kurzen Code (etwa **K7P-4XQ**),
   darunter die Adresse der Hauptkasse und einen QR-Code. Der Code gilt einmal
   und läuft nach 10 Minuten ab.
2. Installieren Sie Universal Till auf dem neuen Gerät, wählen Sie **Bestehendem
   Geschäft beitreten** und geben Sie ihm einen Namen, etwa „Bar“ oder
   „Terrasse“.
3. Tippen Sie entweder Code und Adresse ein, oder tippen Sie auf **Hauptkasse in
   diesem Netzwerk finden** und wählen Sie Ihre Hauptkasse aus der Liste. Bei der
   Suche zeigen beide Bildschirme dieselbe 6-stellige Zahl: Prüfen Sie, dass sie
   übereinstimmt, und ein Manager bestätigt die Anfrage an der Hauptkasse. Das
   Koppeln passiert nie automatisch – ein Gerät in Ihrem WLAN kann sich also
   nicht unbemerkt Ihrem Geschäft anschließen.

Die neue Kasse übernimmt dann das gesamte Geschäft (Produkte, Preise,
Einstellungen, Bestand und Personal); in einem viel genutzten Netzwerk kann das
bis zu einer Minute dauern. Sie bekommt automatisch einen eigenen Kassenplatz,
sodass das Personal sofort eine Schicht darauf eröffnen kann.

## Was die Kassen gemeinsam nutzen

- **Verkäufe** von jeder Kasse fließen zur Hauptkasse zurück, sodass die
  Verkäufe des ganzen Geschäfts an einem Ort landen.
- **Sortimentsänderungen** können Admins und Manager an jeder Kasse vornehmen,
  nicht nur an der Hauptkasse. Sie werden an der Hauptkasse gespeichert und
  erreichen die anderen innerhalb von Sekunden (höchstens einer halben Minute). Bearbeiten zwei Personen
  denselben Artikel, wird die zweite gebeten, neu zu laden, statt die Änderung
  der ersten zu überschreiben.
- **Geschäftsweite Einstellungen** (Zahlungsoptionen, das Bon-Design, die
  Sperrzeit und so weiter) liegen ebenfalls an der Hauptkasse. Einstellungen,
  die nur zu einer Kasse gehören, etwa ihr Drucker oder ihr Bildschirm, bleiben
  an dieser Kasse.
- **Bestand** zählt die Hauptkasse. Eine zusätzliche Kasse lehnt nie einen
  Verkauf ab, weil ihre eigene Kopie des Bestands ein paar Sekunden hinterher
  ist. Verkaufen zwei Kassen gleichzeitig das letzte Stück, erscheint das auf
  dem Dashboard der Hauptkasse, statt einen Kunden aufzuhalten.
- **Gutscheine** gelten im ganzen Geschäft: an einer Kasse verkauft, an jeder
  anderen Kasse einlösbar, die die Hauptkasse erreicht, und zwei Kassen können nicht gleichzeitig dasselbe
  Guthaben ausgeben.
- **Plugins** folgen der Hauptkasse: Dort installiert, lädt jede beigetretene
  Kasse es innerhalb von etwa einer halben Minute herunter und prüft es.
- **Updates** folgen der Hauptkasse ebenfalls. Eine zusätzliche Kasse wechselt
  im nächsten Moment ohne offenen Verkauf auf die Version der Hauptkasse, oder
  sie zeigt einen Hinweis, wo sie Updates noch nicht selbst installieren kann
  (zum Beispiel unter Android).

## Wenn eine Kasse den Kontakt verliert

An einer zusätzlichen Kasse hat die Statusleiste eine Anzeige, die immer in
Worten sagt, was sie bedeutet: **Mit Hauptkasse verbunden** oder **Hauptkasse
nicht erreichbar seit … — Verkauf läuft offline weiter**. So oder so **verkauft
diese Kasse weiter**. Ihre Verkäufe warten auf der Kasse und werden
synchronisiert, sobald die Hauptkasse zurück ist. Solange der Kontakt fehlt,
werden die geschäftsweiten Einstellungen nur zum Lesen angezeigt, mit einem
Hinweis auf den Grund – so nimmt niemand eine Änderung vor, die verloren ginge.

Kommt die Hauptkasse nach einem Neustart unter einer anderen Netzwerkadresse
zurück, findet die zusätzliche Kasse sie von selbst wieder. Sie verbindet sich
nur mit der Hauptkasse, mit der sie gekoppelt wurde, sodass kein anderes Gerät
deren Platz einnehmen kann. Verhindert Ihr WLAN, dass Geräte einander sehen,
kann eine zusätzliche Kasse außerdem beim Cloud-Konto Ihres Geschäfts nachfragen,
wo die Hauptkasse zuletzt war – sofern beide Kassen mit der Cloud verbunden sind.

## Bestellanzeigen, Küchenbildschirme und Selbstbestellung

Zusätzliche Geräte müssen keine Kassen im üblichen Sinn sein. Ein Tablet kann
ein **Selbstbestell**-Bildschirm sein, an dem Kunden ihre Bestellung selbst
zusammenstellen, oder eine **Bestellstatus**-Anzeige, die Bestellungen von jeder
Kasse zeigt, sobald sie eingehen. Der **Küchenbildschirm** einer Station läuft
auf der Kasse, die ihre Bestellungen aufnimmt, auf einem zweiten Bildschirm
daran. Eine Bestellanzeige oder ein Küchenbildschirm zeigt und
aktualisiert Bestellungen während des ganzen Service und fragt nur dann nach
einer PIN, wenn jemand etwas anderes öffnen will.

Jede Kasse im Geschäft läuft mit derselben Software, auf jeder Mischung von
Geräten, die Sie haben: einem [Raspberry Pi, einem PC oder einem
Tablet](/de-de/blog/pos-on-hardware-you-already-own/).
[Laden Sie Universal Till herunter](/de-de/download), um Ihre Hauptkasse
einzurichten, oder [lesen Sie die Anleitung zum Einstieg](/de-de/start).
