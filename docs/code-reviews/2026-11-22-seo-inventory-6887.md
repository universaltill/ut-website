# Review: SEO site inventory export, website half (ut-docs#6887, ADR-0211 section 3.1-3.5)

- **What shipped:** `scripts/seo-inventory.mjs` (+ `lib/seo-inventory.mjs`, `lib/swa-routes.mjs`) writes `dist/seo/inventory.json` at the end of `npm run build`, from the final post-inlined HTML. `data/seo-keyword-map.json` holds term ownership (31 terms, no competitor names); ut-docs `reference/website-keyword-map.md` points to it (branch `docs/6887-keyword-map-pointer`). A hand-kept SWA route serves the file with `X-Robots-Tag: noindex`; the deploy live check asserts 200, noindex and `buildSha == GITHUB_SHA`. `serve-site.js` now shares the route matcher and applies per-route `headers`. The blog index marks English-fallback post cards `lang="en" dir="ltr"` (review fix, below).
- **Deferred (cloud half, `blocked:dep` #6886):** ut-cloud job and tables; ADR-0211 section 3.1/6.2 amendment (key batches on `contentSha256`, not `buildSha`); `helpRef`; ETag / 304 probe; ut-docs `reference/contracts/seo-inventory.md`; word count (derive from `bodyText`); `indexNow[]` contents (#6893).

## Contract (until the ut-docs reference exists)

`JSON.stringify(obj) + "\n"`, camelCase, key order: `schemaVersion` "1.0", `buildSha` (GITHUB_SHA, else git HEAD, else null + problem `no_build_sha`), `deployRunId`, `computedAt` (UTC, no ms), `contentSha256` (SHA-256 of `JSON.stringify({rows, declaredOwners})`), `locales[]` `{code, bcp47, dir, humanReviewed}`, `problems[]` `{path, code, message}`, `declaredOwners[]` `{term, locale, owner, supporting[], card}` (full paths), `indexNow` `[]`, `rows[]` sorted by path: `path, locale, kind, noindex, title, description, canonical, hreflang[], headings[] (h1-h3 in main), bodyText (main only, NFC), links[] {href, area body|chrome, internal, rel}, translated, fallbackElements`. `path` is the sitemap's (percent-encoded) form; the file is looked up by the decoded path.
Build fails on: no sitemap or zero locs, off-host / non-https loc, malformed percent-encoding, unresolvable or redirecting loc, duplicate path, invalid keyword map, size over 30 MiB. Problems (build continues): `no_build_sha`, `unknown_locale`, `no_main`, `multiple_main`, `owner_not_in_sitemap`.
