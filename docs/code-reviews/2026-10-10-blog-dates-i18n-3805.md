# Review: blog dates localised, RTL-safe; honest blog subtitle (ut-docs#3805)

Date: 2026-10-10 · Author: Dev subagent (Sonnet) · Reviewer: independent subagent (Opus, fresh context)

## What shipped
- `src/lib/dates.ts`: `formatDate(date, locale)` runs `Intl.DateTimeFormat(bcp47(locale), { … timeZone: 'UTC' })`.
  - fa-IR renders the Solar Hijri calendar in Persian digits, which is Iran's civil calendar.
  - The UTC zone means a build server's time zone can no longer shift the day.
- Blog index cards, blog post date lines and the legal-page "updated" line now render `<bdi><time datetime="YYYY-MM-DD">…</time></bdi>`.
  - On an RTL page this stops the date run from swapping with ` · author`. Before, `/fa-ir/` showed "October 2026 · Universal Till 6".
  - An English-fallback post or legal page keeps an English date. Its line is already marked `lang="en" dir="ltr"` as the untranslated original.
- `news.sub` was reworded in all 5 locales to "Product news, release notes and guides for Universal Till." No shop stories exist yet. The RSS `DESCRIPTION` got the same change.
- The hardcoded "No posts yet." is now the key `news.empty` in all 5 locales.
- The "News" h1 was already translated by #3811's build-time `t()`. I verified it and changed nothing.
- New `tests/blog-i18n.spec.js` with 10 tests.
