## What shipped
- `src/lib/llmsText.ts` + `src/pages/llms.txt.ts`, `src/pages/llms-full.txt.ts`: llmstxt.org files generated at build from `site/i18n.js` (English), each marketing template's own section order, the route table (`marketingRoutes()`, noindex pages excluded), and the blog/legal collections. Never hand-edited.
- `llms.txt`: H1, summary blockquote, Key pages, FAQ, Blog, Legal, Other languages, Contact, Optional (full file + sitemap) — every item a link, every link absolute.
- `llms-full.txt`: every indexable English marketing page (home, download, start, pilot) and every en-gb blog post in full; post headings demoted below the post title; an MDX import/component in a post fails the build instead of leaking source.
- `staticwebapp.config.json` `mimeTypes` `.txt` → `text/plain; charset=utf-8`; `scripts/serve-site.js` now applies the config's `mimeTypes` (no hard-coded `.txt`), and `deploy.yml`'s live check asserts `/llms.txt` content type on production.
- `marketingPages.ts`: `faqNumbers()` shared by the FAQPage JSON-LD and llms.txt, so both publish exactly the FAQ the page renders.
- Tests `tests/llms-txt.spec.js`; README section.
