# 2026-10-19 — /plugins as small cards + one page per plugin (ut-docs#4645)

**Author:** lane:cloud-41 (Opus 5.5). **Reviewer:** independent Fable subagent, one round (MODEL-ROUTING: complexity:medium).

## What shipped
- `/<locale>/plugins/` is now a grid of small cards: logo (manifest `resources.icon`, else a coloured letter mark), name, the description's first sentence, a type badge and a Free badge. Each card is one link. No description and no buttons on the grid.
- `/<locale>/plugins/<slug>/` exists for every plugin in every locale. It shows the full description, screenshots, a Details box (type, price, version, minimum till version, devices, publisher), "What it may access" (a plain-language line plus the raw permission name) and the Download / Source buttons. Each page has its own canonical URL and hreflang set, and is in `sitemap.xml`.
- `src/lib/plugins.ts` + `plugin-list.json`: one memoised build-time load shared by the grid, the pages, the sitemap and `/plugin-assets/<slug>/<file>`. Pictures are copied into the build so the CSP `img-src` stays `'self'`. They must be PNG/JPEG/WebP by magic bytes (never SVG), with an icon ≤ 512 KB, screenshots ≤ 2 MB, at most 6, a safe relative path and a 15 s timeout. A failure drops that plugin or picture with a warning, never the build.
- 33 new `pluginspage.*` keys in en/tr/zh/fa/de. The unused `pluginspage.repo` is removed.
- CI: `node --test src/lib/plugins_test.mjs` in the `build` job.
